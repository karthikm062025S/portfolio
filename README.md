# Karthik Mandli

My personal site: one page, built with Next.js and deployed on Vercel.

Run it with `npm install` then `npm run dev`.

The golf hole in the "Off the keyboard" section is a Rust simulation compiled to WebAssembly; its source, tests and report are in [golf/](golf/).
